# অন পেজ ডেমো ই-কমার্স ওয়েবসাইট 01 (On-Page Demo E-Commerce Website 01)

**অন পেজ ডেমো ই-কমার্স ওয়েবসাইট 01** হলো একটি আধুনিক, দ্রুতগতির এবং সম্পূর্ণ রেসপনসিভ বাংলাদেশি ওয়ান-পেজ অর্গানিক গ্রোসারি ই-কমার্স ফ্রন্টএন্ড ওয়েব অ্যাপ্লিকেশন। এটি পোর্টফোলিও শোকেস এবং রিয়েল-টাইম কনভার্সন ফোকাসড অনলাইন শপ হিসেবে প্রস্তুত করা হয়েছে।

## মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **বাস্তবসম্মত ক্যাটাগরি ও প্রোডাক্ট সিস্টেম**:
   - ঘি (Ghee): ACME, আড়ং, পাবনা ডেইরি, দেশি গরুর খাঁটি গাওয়া ঘি
   - মধু (Honey): সুন্দরবনের প্রাকৃতিক চাকের মধু, কারকুমা অর্গানিক মধু, ডাবর মধু
   - তেল (Oil): কাঠের ঘানি ভাঙা খাঁটি সরিষার তেল, তিলের তেল, রোজ অয়েল
   - খেজুর (Dates): মদিনার মরিয়ম খেজুর, কালমি খেজুর, খুরমা খেজুর
   - চা পাতা (Tea): কাজী অ্যান্ড কাজী মোরিঙ্গা চা, কেডি হারবাল টি, শ্রীমঙ্গল ব্ল্যাক টি
   - বাদাম ও বীজ (Nuts & Seeds): প্রিমিয়াম মিক্সড বাদাম, রোস্টেড মিষ্টি কুমড়ার বীজ
   - মসলা (Spices): খাঁটি গুঁড়া মসলা কম্বো (হলুদ, মরিচ, ধনিয়া ও জিরা), শাহী আস্ত গরম মসলা
   - শুঁটকি (Shutki): কক্সবাজারের অর্গানিক লইট্টা শুঁটকি, দেশি কাঁচকি শুঁটকি

2. **ডাইনামিক ক্যাটাগরি ফিল্টারিং ও ন্যাভিগেশন**:
   - উপরে হেডার মেনু ও ক্যাটাগরি ক্যারোজেল থেকে ক্লিক করলে সরাসরি সেই ক্যাটাগরির সেকশনে স্ক্রল করে।
   - All Products সেকশনে রয়েছে WoodMart স্টাইলের ক্যাটাগরি পিল বাটন (`সব পণ্য`, `গাওয়া ঘি`, `খাঁটি মধু`, `খেজুর`, `খাঁটি তেল`, `চা পাতা`, `বাদাম ও বীজ`, `মসলা`, `শুঁটকি`)। এক ক্লিকে ইনস্ট্যান্ট ফিল্টারিং সুবিধা।

3. **লাইভ সার্চ ও সাজেস্ট (Live Ajax Search)**:
   - কিওয়ার্ড, বাংলা ও ইংরেজি নাম, হ্যাশট্যাগ এবং ক্যাটাগরি ভিত্তিক রিয়েল-টাইম সার্চ ড্রপডাউন রেজাল্ট।

4. **ইন্টারেক্টিভ কুইক ভিউ মডাল (WoodMart Quick View)**:
   - যেকোনো পণ্যে ক্লিক করলে পপআপে বড় ইমেজ গ্যালারি, থাম্বনেইল, ডিসকাউন্ট ব্যাজ, ৫-স্টার রেটিং, ভ্যারিয়েশন সুইচার (যেমন: ৫০০ গ্রাম, ১ কেজি), লাইভ কোয়ান্টিটি সিলেক্টর।
   - নিচে স্ক্রল করলে বিস্তারিত ট্যাবস: পূর্ণ বিবরণ, পুষ্টিগুণ চার্ট, স্পেসিফিকেশন টেবিল, হ্যাশট্যাগ কিওয়ার্ডস এবং কাস্টমার রিভিউ।

5. **সাইড স্লাইড কার্ট ড্রয়ার (Cart Drawer)**:
   - হেডার কিংবা মোবাইল টুলবারের ব্যাগ আইকনে ক্লিক করলেই মসৃণভাবে সাইড কার্ট ড্রয়ার খুলে যায়।
   - হেডারে রয়েছে কমলা রঙের কাউন্ট ব্যাজ (আইটেম যোগের সাথে সাথে অ্যানিমেট হয়)।
   - কার্টের ভেতরে কোয়ান্টিটি বাড়ানো-কমানো (`-` `+`), পণ্য ডিলিট, ফ্রি শিপিং প্রগ্রেস বার (৳ ১,৫০০ টার্গেট), কুপন কোড অ্যাপ্লাই (`DESHI10`) এবং সাবটোটাল হিসাব।

6. **ওয়ান-পেজ ডাইরেক্ট চেকআউট (Instant Checkout Modal)**:
   - কোনো পেজ রিলোড ছাড়াই পপআপের ভেতরে সরাসরি অর্ডারের নাম, মোবাইল নাম্বার, ঠিকানা এবং ডেলিভারি এরিয়া (ঢাকার ভেতরে ৳ ৭০ / ঢাকার বাইরে ৳ ১২০) নির্বাচন করে এক ক্লিকে ক্যাশ অন ডেলিভারিতে অর্ডার সম্পন্ন করার সুবিধা।
   - অর্ডার সাবমিটের পর ইনভয়েস রিসিপ্টসহ সাকসেস নোটিফিকেশন।

## ব্যবহৃত প্রযুক্তি (Tech Stack)

- **ফ্রন্টএন্ড মার্কআপ:** HTML5, Modern Semantic Architecture
- **স্টাইলিং:** CSS3, Custom CSS Tokens, WoodMart UI Library, Responsive Mobile First Design
- **স্ক্রিপ্টিং:** Pure Vanilla JavaScript (No heavy frameworks required)
- **স্টেট ম্যানেজমেন্ট:** LocalStorage Persistence
- **হোস্টিং ও লাইভ সার্ভার:** Cloudflare Tunnel (Global High Speed Edge)

## লোকাল কম্পিউটারে রান করার নিয়ম (How to Run Locally)

1. রিপোজিটরিটি ক্লোন করুন:
   ```bash
   git clone https://github.com/stl-sahadat/on-page-demo-ecommerce-website-01.git
   cd on-page-demo-ecommerce-website-01
   ```

2. সরাসরি ব্রাউজারে চালাতে `index.html` ফাইলটিতে ডাবল ক্লিক করুন অথবা পাইথন দিয়ে লোকাল সার্ভার চালান:
   ```bash
   python3 -m http.server 5000
   ```
3. ব্রাউজারে ওপেন করুন: `http://localhost:5000`
